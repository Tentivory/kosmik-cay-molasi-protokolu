# Kosmik Çay Molası Protokolü

## Özet (Ciddiye Alın)

Bu proje, insanlık tarihinin en önemli bilimsel başarılarından biridir. Ay'a çıkmak mı? Çocuk oyuncağı. Bu protokol, sonsuz çay molasını simüle eder. Gerçekten çalışır. Gerçekten bitmez. Gerçekten işe dönmezsiniz.

NASA, ESA ve Türk Çay Enstitüsü (hayali) tarafından onaylanmamıştır ama onaylanması gerekirdi.

## Kullanım

```bash
python cay_molasi.py
```

Çıktıyı izleyin. Sabırla. Sonsuza kadar. Bu bir özelliktir, bug değil.

## Neden Bu Proje?

Çünkü iş hayatındaki en büyük sorun, çay molasının bitmesidir. Bu protokol o sorunu kökten çözer. Çay asla demlenmez, molâ asla bitmez. Verimlilik %0, mutluluk %100.

## Lisans

Bu proje "Abi İstiyorsan Al" lisansı altındadır. İstiyorsan çal, istemiyorsan da çal.
